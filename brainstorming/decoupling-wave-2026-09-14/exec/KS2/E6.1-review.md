## Findings
**F1 Critical** — held items lost on Escape and disconnect: MenuListener.java:146-160 tracked close branch untracks + onClose but never returns `ItemHoldingComponent` contents (the bug Oriel fixed, menu-chest #1, `ChestMenuCloseListener.java:69-73`). CraftBukkit closes the inventory before `PlayerQuitEvent` (SPIGOT-5799), so `onQuit` (:164-183) finds nothing and PLAYER_DISCONNECT return is dead. `MenuListener` is final and `MenuTarget` has no user-close hook → Oriel cannot restore it. Fix: `default void returnHeldItemsOnUserClose(Player)` on MenuTarget, called at MenuListener.java:158 after untrack; ChestMenu overrides with the guarded return (F2); listener-level test.
**F2 Important** — dropped double-issue guard on a live race: `closeAll(PLUGIN_DISABLE/RELOAD)` reaches `close(player, reason)` (ChestMenu.java:218-230); Oriel pins it in `DupePreventionStressTest.java:191-217` (`pickupRaceWithPluginDisableDoesNotDupe`). `returnHeldItems` is private. Fix: port `returnHeldItems(player, reason, boolean skipIfSlotEmpty)` from Oriel `ChestMenu.java:684-703` as protected; `true` for close(player, reason) and F1's hook; port the race test.
**F3 Important** — interactive flag stale/reset: (a) `ItemComponent` render calls `view.interactive(false)` (ItemComponent.java:117) so `builder.interactive(13).fill(X)` makes slot 13 non-interactive after first render (test only checks pre-render, ChestMenuBuilderTest.java:129-135); (b) dropped/empty components get `clearHandlers` but not `setInteractive(slot,false)` (ChestMenu.java:318-332); (c) `adoptComponentsFrom` (:433-436) does not adopt `fresh.interactiveSlots`. Fix: decoration never overrides a builder-interactive slot; clear the flag wherever handlers are cleared; adopt the set; post-render tests.
**F4 Important** — `COLLECT_TO_CURSOR` on an interactive top slot collects from non-interactive menu slots (MenuListener.java:78-83; blocked only for bottom :97). Fix: cancel before the interactive check unless `handleDepositClick` accepted; test.
**F5 Important** — extension points missing: `MenuListener` `public final` (:54), private helpers (:96, :186), `InventoryService.registerListeners` hard-codes `new MenuListener` (:57); `ChestMenuBuilder` `public final` (:56), package-private ctor (:82), `build()` hard-codes `new ChestMenu` (:222), private applyBorder/applyLine; `ChestMenu.renderOne` private (:449), `dispatchOnOpen` private (:282), contexts package-private so an Oriel `renderAll` override cannot render.
**F6 Important** — two-service test covers click only (MenuListenerTest.java:63-86); drag, close, quit unpinned.
**F7 Important** — red-first evidence only compile errors (E6.1-report.md:85-100).
**M1** — hardcoded English permission message (ChestMenu.java:185). **M2** — first `open()` with a title always recreates the inventory (`lastResolvedTitle` null; ChestMenuBuilder.java:220-221, ChestMenu.java:402-410).
