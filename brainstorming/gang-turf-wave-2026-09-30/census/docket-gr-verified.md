## Roadmap read-out

- Gang-onboarding cluster (GR-11, 23, 24, 29): invite and create flow. The invite lifecycle and name rules should be fixed before any redesigned join flow, map labels or recruitment UI.
- Rank-tree integrity cluster (GR-13, 21, and 22/28/12 alongside): needed only if the redesign keeps the head/tail `Tree<Rank>`. If it replaces the tree with role flags, GR-12/13/21/22/28 become obsolete and the migration must be planned instead.
- GR-19 (dead level/bounty events) is a prerequisite decision: either wire them as gang-progression hooks for turf or delete them.
- Cheap null-safety fixes (GR-14, 15, 28, 30, 34) are batchable into one "gang command hardening" task and do not gate the redesign.
- Persistence hygiene (GR-20, 31, 32, 33) is independent; GR-32's `initializeMemberData` is dead code to delete.
