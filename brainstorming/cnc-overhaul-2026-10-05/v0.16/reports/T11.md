## Rulings
- Ruling: the RESTORE handling (no seed, rejoin grace) applies only when `Cops.Dispatch.Enabled` is true - Rejoin_Grace is
  a Dispatch key and CONSTRAINTS says a feature switched off restores 0.15.2 - if wrong, a server with Dispatch off but
  the breather on would seed a rejoin at the player's position (0.15 behaviour) instead of holding.
- Ruling: `casualtyWithin` reads a new `lastCasualtyAt`, not `casualtyTimes` - `startRegroup` clears `casualtyTimes`, and
  the casualty that triggers a regroup is often the one that wipes the squad, so the wipe (and its breather) would be
  missed - none known.
- Ruling: a station's spawners also honour `Spawner_Max_Y_Diff` (as `findClosestSpawnerLocation` does) besides
  `Spawner_Preference_Radius`, `allowed` and `isOutOfSight` - C8 names only the radius, but a spawner storeys away is the
  unreachable case that filter exists for - if wrong, such a spawner is skipped for the hidden ring.
- Ruling: the plan is computed once per batch (same inputs for every missing slot in one pass) and the radio `%eta%` is
  the whole wait (`arriveAt - now`, rounded up: hold + ETA); the DISPATCH debug line keeps `eta=` (plan) and `hold=`
  separate - a wiped squad's "Backup inbound in 13 s" is then the real wait - none.
- Ruling: the station-side cone is built as a `SpawnBias(target->station bearing, target, Long.MAX_VALUE, 60)` and reuses
  `SpawnBias.ahead` (no extra public helper) - one cone rule for both - none.
- Ruling: `SpawnBias.ahead` returns true when the heading or the offset has no horizontal length (no direction to compare)
  - none.
- Ruling: commit subject in repo style `cops-n-crooks: ... (T11)` as the orchestrator's prompt says (CONSTRAINTS shows
  `cnc-0.16 T<N>:`; the merged T7/T10 lanes used the repo style) - cosmetic.
