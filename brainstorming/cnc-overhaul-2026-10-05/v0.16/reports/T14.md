# Task 14 Report: Turf RegionProvider

**Status:** COMPLETE

## Summary

Task 14 implements the Turf RegionProvider to publish owned and unclaimed turfs as named regions through the PlaceNames API. This allows other systems (dispatch, perimeter, hideouts) to discover turfs and their metadata without direct dependencies.

## Files Implemented

### Main Implementation
- **`gangland-features/gangland-turf/src/main/java/org/luckyraven/gangland/turf/place/TurfRegionProvider.java`** (new)
  - Implements `RegionProvider` interface per CONTRACTS C1
  - Returns turf regions found at a location via `TurfManager.findAt()`
  - Tags unclaimed turfs with `{turf}` and owned turfs with `{turf, hideout}`
  - Encodes turf ID as "turf:<id>" and uses `Cuboid.column()` for Y-unbounded regions

- **`gangland-features/gangland-turf/src/main/java/org/luckyraven/gangland/turf/TurfModuleConfig.java`** (modified)
  - Added imports: `PlaceNames`, `TurfRegionProvider`
  - Added bean method `turfRegionProvider(TurfManager turfs, PlaceNames places)` to instantiate and register the provider

### Tests
- **`gangland-features/gangland-turf/src/test/java/org/luckyraven/gangland/turf/place/TurfRegionProviderTest.java`** (new)
  - `unclaimedTurf_isATurfWithNoOwner` - verifies NO_OWNER and TAG_TURF only
  - `ownedTurf_isAHideoutOwnedByTheGang` - verifies owner and both tags
  - `outsideEveryTurf_isEmpty` - confirms empty list when location has no turf
  - `yIsIgnored` - confirms Y coordinate is ignored (column regions)
