## Rulings
- Ruling: firstHit stores a monotonic hit-order counter, not a timestamp - C16 says first-hit "maps" of times with `<`; two hits in the
  same millisecond (tests, projectile bursts) tie and would read killer-first - none if wrong (window still uses `clock`/lastExchange).
- Ruling: when Pay_Notoriety pays a notoriety-only target (posted == 0) the self-defence check still applies afterwards (kill is not a
  crime if self-defence), a posted>0 payout always returns before it - C16 text ambiguous on this combination - low.
- Ruling: allied/same-gang killer: no payout, bounty stays, then handleBounty + crime path run as for any other player kill.
- Ruling: UserDataLoader starts the timer only when notoriety > 0 and < max (legacy NULL rows are all posted, so no timer) via
  `runTask` always (inline under BukkitStatics) - cost: none.
- Ruling: restoreLedger("") is "no ledger": whole amount is notoriety (a row saved by 0.15 with no posters).
