## Test Results

### Red-First Verification
The new test assertion `assertTrue(report.issues().toString().contains("AUTO"), ...)` would have failed against the pre-change code because:
- The old `DropMode` enum had only `ONE_STAR` and `ALL_STARS`
- The old warning message text said "(ONE_STAR or ALL_STARS)"
- The word "AUTO" would not appear in the message

### Green Results
All tests pass after the changes:
```
mvn -q -pl gangland-features/cops-n-crooks -am test -Dtest=ChaseConfigTest -Dsurefire.failIfNoSpecifiedTests=false
Exit code: 0
```

The `ChaseConfigTest.unknownDropMode_fallsBackToOneStar_andReports()` test now passes all assertions:
- Falls back to `DropMode.ONE_STAR` when an unknown mode is provided
- Report is not empty
- Report message contains "AUTO"
