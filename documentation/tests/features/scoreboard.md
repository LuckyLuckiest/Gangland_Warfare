## Overview

The scoreboard is no longer part of Gangland Warfare as of 0.10.0. It now lives in **Plaque**, a standalone
Keystone-powered Spigot plugin (`E:\Programming\java\Plaque`) with no dependency on Gangland, which renders
scoreboards through real PlaceholderAPI `%gangland_*%` tokens that Gangland's own placeholder expansion still
publishes. Its test checklist now lives in that repo.
